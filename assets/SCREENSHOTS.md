# 截图清单 / Screenshot checklist

`README.md` 的「🎬 截图 / Screenshots」章节引用本目录下的 10 张图。
在补齐之前，README 里这些位置会显示为坏图，属预期状态。

## 通用拍摄要求

- **分辨率**：应用窗口拉到 **1920×1080**（或至少 1600×900）后截图，不要截整个桌面。
- **格式**：PNG，文件名严格按下表，放在本目录（`assets/`）下。
- **主题**：10 张统一用同一个主题（推荐**深色**，和 README 的紫色徽章更搭）。
- **内容**：尽量用同一首歌贯穿全流程，截图之间有连续感。
- **隐私**：截图前检查路径栏、最近文件列表、Cookie / 登录态里有没有不想公开的信息。
- **体积**：单张建议压到 500 KB 以内（可用 TinyPNG / `oxipng` 之类无损压缩）。
