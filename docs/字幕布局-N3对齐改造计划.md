# 字幕布局 N3 对齐改造计划

本文基于《NicokaraMaker3字幕布局逆向.md》与当前模块（`krok_helper/subtitle_render`）的对比分析，
列出布局设置的功能差距、按优先级排列的改造任务，以及属性面板的 UI 整理方案。

分析时点：2026-07-03，分支 `feat/subtitle-render`。

## 一、现状盘点

布局相关设置目前分散在属性面板（`frontend/property_panel.py`）的两个 tab：

**「布局」页**（`_make_basic_page`，3 个分组、26 个控件）：

| 分组 | 控件 |
|---|---|
| 视图（5 项） | 对齐锚点九宫格、位置 X、位置 Y、缩放 %、旋转 ° |
| 位置（15 项） | 双行显示、从右到左、竖排、行位置（顶/中/底）、下行底边距、水平布局（上左下右 / 居中 / 逐行独立）、两行间距、上行左边距、下行右边距、逐行独立的 一行/二行 对齐 + X + Y |
| 时间（6 项） | 提前入场、延迟退场、偏移、分段间隔、段落结束、同步退场 |

**「字体」页上的布局相关项**：字间距（= N3 歌詞間隔）、空格宽度 %、允许文字咬合（= AllowBiting）。

**「字幕」页注音小节**：注音字号、注音间距（= 歌詞とルビの間隔）。

## 二、与 N3 布局面板逐项对比

N3 `LyricsLayoutModel` 12 个字段 + 管理机制，对照结果：

| N3 字段 | 我们 | 状态 |
|---|---|---|
| 上下配置 Top/Middle/Bottom | `line_y_position` | ✅ 已有 |
| 上/下余白 | `line_y_margin_px` | ✅ 已有（单值随锚点切换，语义一致） |
| 歌詞間隔 | `letter_spacing_px` | ⚠️ UI 下限为 0，N3 允许负值 |
| 行間 | `line_gap_px` | ⚠️ 引擎 `max(gap, 0)` 钳制，N3 允许负值重叠 |
| AllowBiting | `allow_biting` | ✅ 已有 |
| 歌詞とルビの間隔 | `ruby_gap_px` | ✅ 已有（同样不支持负值） |
| 左右余白（单值双侧） | `upper_line_left_margin_px` + `lower_line_right_margin_px` | ⚠️ 语义偏差：我们是双行专用的两个值，N3 是一个 margin 同时约束左右 |
| 行ごとの左右レイアウト（任意行数列表） | 固定 2 行（asymmetric / center / per_row） | ❌ 缺：任意行数 + Bottom 从下向上映射 |
| スマート水平配置 None/Single/Multi | 无 | ❌ 缺 |
| ルビ間隔（ruby 字符间距） | 无模型字段/UI | ❌ 半缺：`painter._ruby_interval_px` 已在读 `ruby_interval_px`，但 `Style` 没有该字段、UI 无入口，实际恒为 0 |
| ルビ配置 Auto/Center/EqualSpace | 无开关 | ⚠️ 半缺：引擎已实现 N3 EqualSpace 公式（`_ruby_equal_space_gap`，含居中溢出），缺 Auto/Center 分支与用户开关 |
| 布局设置名称 + 多布局定义 | 单一全局 `Style` | ❌ 缺 |

**机制层面缺失**：

- 多布局集合 + 页级 `LayoutIndex`（同页联动应用）；
- `SizeAndRatio` 输出高度缩放；
- 自动布局选择器（按页行数匹配 / 全部统一）；
- 布局模板、复制、tab 排序；
- 左右余白溢出 / 侵入警告。

**我们有而 N3 没有的**（保留）：视图整体变换（位移/缩放/旋转）、竖排、从右到左、逐行 Y 偏移、
「时间」组（N3 中属表示时刻选择器，不在布局页）。

## 三、改造任务（按优先级）

### P1：低成本补齐（不动架构，可进当前 feat 分支）

1. **负值放开**：`line_gap_px` / `letter_spacing_px` / `ruby_gap_px` 的 SpinBox 下限改负数，
   删除 painter 中对应 `max(..., 0)` 钳制（`_resolve_display_baselines` 等处）。
   注意竖排复用 `line_gap_px` 当列距，需确认负值不出错。
2. **`ruby_interval_px` 字段落地**：`Style` 加字段 + 序列化 + UI SpinBox。
   引擎已在读该属性，几乎零引擎改动；顺带修正相邻 ruby 避让的间距语义。
3. **`ruby_alignment`（auto / center / equal_space）**：补 Center 分支（整组居中、不摊分间距）
   与 Auto 判定（正文或 ruby 全英数 → Center，否则 EqualSpace），加枚举字段 + 下拉框。
4. **左右余白警告**：预览时按行几何检查「溢出画面（Warning）/ 侵入余白（Information）」，
   以 InfoBar / 状态栏提示。纯前端增量。

### P2：SmartHorizon（中等成本）

在 painter 行 X 定位（`_line_x0` 附近）加二次修正：

- 新增 `smart_horizontal: Literal["none", "center_position", "equal_margins"]`，
  默认 `equal_margins`（对齐 N3 默认 Multi）；
- 单行页：非 none 直接居中。注意与现有「段落最后一行居中」逻辑
  （NKM3 EmptyLineBreaker 逆向）合并——两者在 N3 里同属 `SetOneLineX`，借此统一；
- 多行页按逆向文档中的 Single / Multi 公式实现（纯函数，配单测）。

### P3：任意行数布局列表（架构改动，单独分支 / PR）

把「双行」硬编码升级为 `line_alignments: list[HorizontalAlign]`：

- 列表长度 = lane 数；`dual_line_layout=True` ≙ `["left","right"]`，False ≙ `["center"]`，
  旧字段做迁移映射后保留读取兼容；
- `_resolve_display_baselines` 从写死 `{0,1}` 改为按列表长度循环累加；
  Bottom 锚点按 N3 规则从列表末尾向上倒着取，溢出行沿用端项；
- timeline 的 lane 分配从 mod 2 改为 mod N；
- 左右余白收敛为单一 `horizontal_margin_px`（Left 行贴 margin、Right 行贴 width−margin），
  替代现有上左/下右两个字段（迁移：两者默认均为 50，可直接取用作单值）。

这是 N3 对齐里收益最大的一步——完成后「下寄せ3行」「コーラス居中单行」等预设才可能成立。

### P4：多布局定义 + 页级应用 + SizeAndRatio（1.0 后独立 milestone）

- `RenderProject` 增加 `layouts: list[LyricsLayout]`，把 P1–P3 的布局字段挪入（或引用入）布局对象；
  歌词行加 `layout_index`，应用时按页联动（同页所有行同 index）；
- 歌词列表（lyrics_list）加「布局」列 / 右键菜单，支持多选批量应用；
- 自动选择器：按页行数匹配 `len(line_alignments) == 页行数`，找不到行数递减再找；
  以及「全部统一」模式；
- `SizeAndRatio`：布局像素字段存 `(size, ratio)` 对，输出高度变化时
  `size = int(new_h * ratio)`（向 0 截断），保证换分辨率排版一致。

牵动 `.yurika` schema、歌词列表 UI 和预设系统三处，故独立立项。

## 四、UI 整理方案

现状问题：

1. 「时间」组不是布局，占布局页近一半；
2. 「位置」组把书写方向、垂直锚点、水平布局、双行开关混在一张卡片，15 个控件无层次；
3. 字间距/咬合在「字体」页、注音间距在「字幕」页——同一语义域切成三处
   （N3 里歌詞間隔本就是布局页字段）。

目标结构（导航从 4 页扩到 5 页：字幕 / 布局 / **时间** / 特效 / 标题）：

**「布局」页**（自上而下，贴近 N3 布局面板分区）：

| 小节 | 内容 |
|---|---|
| 1. 行结构 | 每行对齐列表（P3 前显示现有双行 + 水平布局三模式；P3 后换成可增删的行列表，Bottom 布局「添加 = 向上插行」）+ 智能水平配置下拉（随 P2 加入） |
| 2. 垂直 | 上下配置（顶/中/底）、上·下余白（标签随锚点切换，Middle 时禁用，对齐 N3 显隐逻辑）、行间距（允许负） |
| 3. 水平 | 左右余白（单值）、字间距（从字体页迁来）、空格宽度、允许咬合 |
| 4. 注音布局 | 注音字号、与正文间距、注音字间距（新）、注音配置（新：自动/居中/均等）——从字幕页迁来 |
| 5. 书写方向 | 竖排、从右到左（全局模式开关，独立小节） |
| 6. 视图 | 保留现状，默认折叠（本项目特有的整体变换，使用频率低） |

迁移后「字体」页只剩字体族/字号/字重/斜体/英数字体，更纯粹。

**「时间」页**：现「时间」组 6 项原样搬走；可择要补上 `Style` 中尚无 UI 入口的
`line_lane_gap_ms` / `line_pair_second_delay_ms` / `line_max_hold_ms` 等字段。

整理后「布局」页与 N3 布局面板逐项可对照，P3 / P4 落地时行结构小节原地升级即可，
不再需要调整信息架构。
