## B. 双模式数据流

### Standalone
- **入口**：`python -m krok_helper.subtitle_render`；项目命令栏或 `Ctrl+N/O/S/Shift+S`
- **加载**：三个独立选择按钮——字幕（`.sug` / `.lrc`）/ 背景视频 / 音频
- **存储**：项目 → `.yurika`；全局首选项 → `AppSettings.subtitle_render` dict
- **装饰**：独立窗口标题 + 项目命令栏；当前没有传统 `QMenuBar/QStatusBar`

### Embedded
- **构造**：`SubtitleRenderWindow.for_embedding(parent, settings_provider, workflow_context)`
- **上游数据**（自动获得，左侧素材区只读）：
  - 字幕：优先直接读取嵌入式 SUG 的 `ProjectStore.project`；打开已有文件时也可读取 `.sug`。`.lrc` 仅作为既有 Nicokara 逐字 LRC 的兼容入口，不再要求第 4 步先导出中间 LRC。
  - 背景视频：`context.aligned_video_path`（第 2 步对齐后的 1080p60 mp4），**默认作为背景层**
  - 音轨：与背景视频同源（mux）或独立流
  - 偏移：`context.alignment_offset_ms`
- **下游交付**：写 `context.subtitle_video_path`，发 `workflow_step_completed` 信号
- **宿主关系**：与 standalone 共用项目命令栏和编辑界面，由 `for_embedding()` 注入设置桥与 WorkflowContext

### 设置桥
- 骨架已实现 `KrokHelperSubtitleRenderSettingsBridge`（`krok_helper/subtitle_render/settings_bridge.py`），仿照 SUG 的 `KrokHelperSettingsBridge`（`gui_qt.py:182-244`）
- 暴露字段示例：`default_font_family` / `default_resolution` / `default_fps` / `prefer_hwenc` / `output_dir` / `recent_style_presets`——存进 `AppSettings.subtitle_render` dict 的对应 key

### 各区组件（qfluentwidgets 渐进引入，歌词列表已完全 fluent 化）

- **顶部项目命令栏**：新建 / 打开 / 保存 / 另存为 / 预览窗口；standalone 与 embedded 都显示
- **素材与导出控制**：字幕 / 背景视频 / 音频选择与加载状态、输出参数和渲染按钮
- **左·歌词列表**：qfluentwidgets `TableWidget`，四列——`轨` / `角色`（双击弹出 FluentComboBox 下拉选配色方案）/ `特效`（双击编辑逐行入退场动画，右键批量应用）/ `内容`（歌词文本，只读不可编辑）。表头可见，行高紧凑布局。点击整行跳转预览到该句起始时间戳；playhead 高亮当前行（待接入 painter 时间同步）
- **中·预览区**：`QGraphicsView` + 自定义场景——当前产品路径用 `QMediaPlayer.setVideoSink` 取视频帧，字幕层由 QPainter 离屏叠加；纯色 / 静态图 / 图片序列背景待 B6 接通。预览与导出共用同一 `paint_frame`
- **中·播放控件**：播放 / 暂停 / 时间码 / 跳转滑块；由统一播放控制器同步视频、音频和字幕时钟
- **右·属性面板**：`QTabWidget` 五标签 —— 基本（屏幕预设 / 像素纵横比 / 宽高 / 视图）/ 字幕（字体 / 字号 / 颜色 / 描边 / 阴影 / 角色方案管理）/ 特效（动画 / 渐变 / 发光）/ 装饰（时段图片 P2）/ 标题（标题字幕编辑）；每个标签内用 `SettingCardGroup` 折叠分组
- **底·字幕轨道**：`QGraphicsScene` 自绘——多行（T1/T2/T3）色块，每行展示一段歌词的演唱区间，块内细分到字符级；按演唱者上色；点击块可定位到对应行 / 字
- ~~底·波形~~：**已弃用**，不做波形图功能

## E. 渲染引擎技术选型

**已选定：QPainter 离屏 + ffmpeg rawvideo pipe**（不要改方案，已与用户达成一致）

- 当前流程：枚举每帧 t → `QPainter` 画到 `QImage(Format_RGBA8888)` → bytes → ffmpeg stdin (`-f rawvideo -pix_fmt rgba`) → 与背景视频合成并编码；B6 完成后再扩展为通用背景输入 + 独立音频输入
- **关键优势**：
  1. 卡拉ok填充逐像素精确，渐变/发光/动画完全自由
  2. **预览与渲染共用 QPainter 绘制函数**，所见即所得
  3. 直接复用 `krok_helper/ffmpeg.py` 的 `run_command` / `find_tool` / `probe_media`
  4. 硬编探测沿用 `audio_alignment.py::export_aligned_video_v2`（参考其分支判断写法）
- **缓解 CPU 占用**：多线程绘帧（producer N×QPainter → 队列 → 单 consumer 喂 ffmpeg），目标 1080p60 实时倍率 ≥ 0.5×

**预览策略**：同引擎降分辨率（`QImage(960, 540)`），定位用 `QMediaPlayer.setPosition()` 取静态背景帧，叠加 QPainter 字幕。保证"预览=输出"。

**否决方案**（避免重新讨论）：
- ❌ 生成 `.ass` + libass burn-in：渐变 / 发光 / 复杂动画表达受限；预览路径割裂。可作为 P2 "极速导出"按钮，但不是主路径。
- ❌ Pillow / Skia / Web 离屏：与现有 PyQt 基建脱节、PyInstaller 打包冲突。

## H. 已确认的产品决策（不要重新讨论）

1. **嵌入模式下字幕传递**：**直接消费 SUG 项目**——第 5 步优先读取嵌入式 SUG 的 `ProjectStore.project`，standalone/项目文件入口支持 `.sug` 路径；不再要求第 4 步先导出 Nicokara LRC。
   - 原因：`.sug` 保留毫秒级 checkpoint、未打/多 checkpoint 语义、注音分段、演唱者/分色信息，避免 LRC 中间层量化和信息损耗
   - 模块内部统一转换成 `TimingTrack`；入口包括 `load_from_sug_project(project)`、`load_from_sug(path)` 与兼容入口 `load_from_lrc(path)`
   - `.lrc` 继续作为外部 Nicokara 文件导入格式保留，但不是工作流主路径
2. **嵌入模式背景默认行为**：默认叠在第 2 步对齐后的 MV 上。当前通过 `_video_path` 实现；不要误认为 `Background` dataclass 已接入产品路径。
3. **背景扩展目标**：B6 已支持 video / image / image_sequence / solid；独立 `SoundPath` 仅供非视频背景导出。视频只使用内嵌音轨，避免双时钟。图片序列字段形态按 NicoKaraMaker3 实际 `ImagePath` 语义处理。
4. **FPS**：只支持 60/120fps；N3 其他帧率统一回退 60，不实现 30fps 原样输出。
5. **N3 布局字符域**：`LyricsInterval` / `AllowBiting` / `RubyInterval` / `RubyAlignment` / `LyricsAndRubyInterval` 属布局排版参数，应进入每个 `LyricsLayout`；字体族、字号、字重、颜色、描边和发光仍属于角色/样式。
6. **假名字体**：不支持独立假名字体族，统一沿用日文/汉字字体；英数字体分离继续支持。该行为不再作为功能缺失警告。
7. **输出格式**：产品只输出 MP4；不支持 AVI、ARGB/透明 PNG 序列。导入非 MP4 N3 工程时转换为 MP4 目标，只做普通提示。
8. **逐行特效**：全局特效是默认值，`TimingLine.animation_override` 只保存差异；UI 支持逐行/批量编辑、独立入退场和时长。N3 已映射 NoAction 与 LineFadeInFadeOut，未知动作遇真实工程再逐项逆向。
9. **标题槽位**：当前保留单个 `TitleOverlay`。TACTIC 的 3 个槽位只有第 1 个非空，不构成损失；遇到真实多标题工程再升级为列表。
10. **二重描边**：严格按 N3 `UseEdge2` fallback 语义；没有启用布尔值时保持关闭，不能因 `EdgeSize2` 存在而强制开启。
11. **垂直書き**：B9 已实现，不再属于待办。
12. **角色文件**：应用内分组样式预设库已实现，预设作为单角色样式模板使用；跨项目单文件交换采用规划中的 `.yurikarole`，旧 `.krstyle.json` 不再进入当前主线。
